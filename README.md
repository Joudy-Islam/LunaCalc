## LunaCalc
An interactive calculator with basic operations, a history list, and keyboard support, with a modern, dark-themed purple design.
**[Live Demo](https://Joudy-Islam.github.io/LunaCalc/)** | **[View Repository](https://github.com/Joudy-Islam/LunaCalc)**

# Keyboard Support
- AC - Escape
- DEL - Backspace/Delete
- = - Enter
- + - +
- - - -
- × - *
- ÷ - /
- % - %
- . - .
- 0-9 - 0-9
